# 🗝️ Interview Prep — Key Notes (Cheat Sheet)

## Before Every Interview

```
□ Research the company (product, tech stack, recent news)
□ Review the job description — prepare 1 example per requirement
□ Test webcam + internet
□ Open your portfolio website for screen sharing
□ Have water + paper + pen ready
□ Warm up: solve 1 easy LeetCode problem
□ Review your 5 STAR stories
```

---

## STAR Method Template

```
S → Situation:  Set the context (where, when, what project)
T → Task:       Your specific responsibility
A → Action:     What YOU did (be specific, use "I" not "we")
R → Result:     Quantifiable outcome (numbers, percentages, impact)
```

## Top 10 React Questions — Quick Answers

| # | Question | One-Line Answer |
|---|---|---|
| 1 | Virtual DOM? | Lightweight JS copy of real DOM; React diffs and batch-updates only changes |
| 2 | useState vs useRef? | useState triggers re-render, useRef doesn't |
| 3 | useEffect cleanup? | Return function runs on unmount or before re-run (clear timers, unsubscribe) |
| 4 | Controlled vs Uncontrolled? | Controlled: React state drives input. Uncontrolled: DOM manages its own state |
| 5 | useMemo vs useCallback? | useMemo caches a value, useCallback caches a function reference |
| 6 | Context vs Redux? | Context: simple global state. Redux/Zustand: complex state with frequent updates |
| 7 | Key prop? | Helps React identify list items for efficient re-rendering |
| 8 | Error Boundary? | Class component with `componentDidCatch` to catch render errors |
| 9 | React 18 new features? | Concurrent rendering, automatic batching, useTransition, Suspense |
| 10 | CSR vs SSR? | CSR: render in browser. SSR: render on server (faster initial load, better SEO) |

## Top 5 Python Questions

| # | Question | One-Line Answer |
|---|---|---|
| 1 | GIL? | Global Interpreter Lock — only one thread executes Python at a time |
| 2 | Decorator? | Function that wraps another function to add behavior |
| 3 | *args **kwargs? | *args = tuple of positional args, **kwargs = dict of keyword args |
| 4 | List vs Tuple? | List: mutable, slightly slower. Tuple: immutable, hashable, slightly faster |
| 5 | async/await? | Coroutines for concurrent I/O without threads (event loop) |

## Salary Negotiation Template

```
"Thank you for the offer! I'm very excited about the role.
Based on my skills in [React, Python, AI/ML, Docker] and
market research, I was hoping for a range of [X-Y].
Can we discuss this?"
```

**Rules:**
- Never give your number first
- Always ask for 24-48 hours to consider
- Having multiple offers = strongest leverage
- Total comp = Base + Bonus + ESOPs + Benefits
