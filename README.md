# Premium Engineering Portfolio

Welcome to my **Premium Engineering Portfolio** repository. This project is a highly dynamic, visually impressive web application designed to showcase complex engineering systems including AI models, automated trading bots, and data pipelines. 

## 🚀 Features

- **Interactive UI**: Fluid page transitions, staggered item loading, and micro-animations powered by **Framer Motion**.
- **Smooth Scrolling**: Implemented using **Lenis** for a modern, buttery-smooth browsing experience.
- **Node-Based System Visualization**: Interactive node graphs using **React Flow** to map out automated trading bot logic and AI workflows.
- **Dynamic Content Rendering**: Uses `react-markdown` and `shiki` to render beautifully highlighted, Markdown-based documentation and articles directly on the platform.
- **Data Visualization**: Charts and system performance metrics via **Recharts**.
- **Modern Styling**: Responsive, glassmorphism-inspired design crafted with **Tailwind CSS**.

## 🛠️ Tech Stack

- **Framework**: React 19 & TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, PostCSS
- **Animations**: Framer Motion
- **Routing**: React Router v7
- **Specialty Libraries**: React Flow, Recharts, Shiki

## 💻 Running Locally

To get the portfolio running on your local machine, follow these steps:

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone <your-repo-url>
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   Navigate to `http://localhost:5173` (or the port specified in your terminal).

## 📂 Project Structure

- `src/components`: UI components, charts, and interactive node elements.
- `src/pages`: Distinct pages of the portfolio (e.g., Home, AI, Projects, Articles).
- `src/data`: JSON/Markdown data backing the projects and documentation.
- `public`: Static assets, images, and fonts.
